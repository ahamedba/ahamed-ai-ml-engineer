# Programme documents

This folder holds the two documents that govern the programme. Both are written by the Principal Mentor, Srinivasan Gurukannan.

| File | What it is |
|---|---|
| `Programme_Objective_Ahamed_Basha_J.md` | The programme objective: what the programme is for, the ten core competencies, the engineering approach, the rule that AI is used as an assistant while Basha owns the work, and the final graduation test. |
| `Approved_20_Week_Plan.md` | The approved plan: 20 weeks, 5 learning days a week, 4 hours a day, on Microsoft Azure. It has the week-by-week table, the Azure rules, the job-readiness track, the evidence and gate rules, and the list of open points. |

## How to use them

- Read the objective first, then the plan.
- For the number of learning days a week, the cloud provider and the capstone, follow the plan. The objective leaves some of these open. The plan lists what is still undecided in section 9, and nothing marked open there is a decision.
- The Principal Mentor decides when Basha moves on from a week or module. The documents describe the work and the evidence. They do not move him on by themselves.
- Do not edit these files. If something looks wrong or unclear, tell the mentor.
